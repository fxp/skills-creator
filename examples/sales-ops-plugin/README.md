# Sales Ops

Digital Sales Ops Associate — pipeline review, prospect research, weekly reports.

## Skills

- `prospect-research`
- `call-prep`
- `pipeline-review`
- `battlecard-update`

## Commands

- `/sales-ops:weekly-report`

## Setup

1. Install via `/plugin install sales-ops` or place under `~/.claude/plugins/sales-ops/`
2. Set environment variables: SLACK_TOKEN, NOTION_TOKEN
3. `/reload-plugins` to activate

## Usage

Skills auto-trigger based on context. Commands are explicit:

```
/sales-ops:weekly-report
```
